# Website surface brief

Scope: the DepTrace showcase website (`site/index.html`, `site/styles.css`). Visitor mode: Persuade.
Audience: developers and tech leads evaluating an architecture checker for a TypeScript/JavaScript repository. Action: install from npm (`npm install -g deptrace-cli`), then the quick start. Proof: real product output from the sample project tests/fixtures/storefront (a real violation, real dashboard screenshots, real check output); no invented customers, numbers or claims. Constraints: static HTML/CSS, no JavaScript, no third-party resources (strict CSP), light and dark themes, served by Caddy at deptrace.sarthxkz.in.

## Direction contract

THESIS: The page is a library call slip for your codebase: the visitor requests DepTrace by its call number (the install command) and the retrieved catalog card, a real violation, comes back with it. It refuses the category's split hero (headline beside a screenshot) and the row of equal feature cards.

OWN-WORLD: The established Catalog Cards world (DESIGN.md) at landing-page volume: the oak drawer colour owns the hero and the closing band (committed strategy); white ruled index stock with blue ruling lines for the slip and cards; one index-card red rule per pulled card; status red and the "new" badge only where they carry meaning; system sans set large and tight for headlines; mono only for call numbers, paths, rule ids and commands. Hairlines, never shadows.

STORY: In one screen the visitor reads what DepTrace is (the slip's Title and Subject), sees it catch a concrete broken layer rule with the exact import and line (the pulled card), and can copy the install command; below, the retrieved materials (dashboard, rules, CI output, quick start) confirm it, and the oak closing band repeats the action.
